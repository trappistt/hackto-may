# hackto-may

A small, dependency-free starter repo for a hackathon demo. It gives you a polished single-page app, simple local persistence, and a tiny Node static server.

## Quick Start

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

## What Is Included

- `index.html` - app markup
- `styles.css` - responsive UI styles
- `app.js` - editable demo state and local save behavior
- `server.js` - zero-dependency local static server
- `.env.example` - starter environment variable placeholders

## Hackathon Flow

1. Replace the product name, pitch, and demo steps in `app.js`.
2. Add your real API calls or mock data where the comments point you.
3. Keep the demo focused on one crisp user journey.
4. Practice the 90-second pitch with the timer running.
